# 02 — Justificación (plantilla completa con ejemplos)

---

## 1. ¿Por qué este proyecto? — EJEMPLO COMPLETO

Porque formaliza un proceso real (alquiler de libros físicos) con software multiplataforma: **app iOS** consumiendo **API REST propia**, persistencia **Core Data**, autenticación moderna (**email + Facebook**), pagos móviles (**Yape**) y un asistente (**Watson**), alineado a tres cursos del sexto ciclo.

Además aporta valor al negocio: menos pérdidas (UID + garantía ≥ valor del libro) y mejor control de plazos (el tiempo corre desde el pago).

---

## 2. Aporte / impacto — EJEMPLO COMPLETO

| Dimensión | Descripción |
|-----------|-------------|
| Económica | Se cobra alquiler (ingreso) y se resguarda reposición con garantía; menos pérdida de stock |
| Operativa | Admin ve títulos, ejemplares, alquileres y confirma recojo/devolución en un flujo digital |
| Social / educativa | Facilita acceso temporal a libros físicos sin comprar el ejemplar |
| Tecnológica | Integra REST, Core Data, Firebase, Facebook, Spring Boot, pruebas Java y Watson |
