## Objetivo 1 — EJEMPLO COMPLETO

| Criterio | Descripción |
|----------|-------------|
| Específico | Desarrollar app iOS + API que permitan alquilar un ejemplar (UID) con pago Yape (alquiler + garantía) y recojo en local |
| Medible | Al cierre del ciclo: flujo completo demo (login → catálogo → pago → reserva → recojo → devolución) sin errores críticos |
| Alcanzable | Stack conocido en cursos (Swift/UIKit, Spring, herramientas cloud del sílabo) |
| Relevante | Resuelve la problemática de control de ejemplares y cobros; cumple REST + Core Data |
| Tiempo | Antes de la Evaluación Final del Proyecto Integrador / proyecto Móviles (según cronograma del ciclo) |

**Enunciado formal:**  
Desarrollar e implementar, antes del EF del ciclo, el MVP de LibreriaRent (app iOS + API Spring Boot) que permita alquilar ejemplares físicos con pago Yape y control de estados, demostrable en sustentación.
