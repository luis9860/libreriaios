## 2. Pantallas MVP — EJEMPLO

| Pantalla | Objetivo | Elementos clave |
|----------|----------|-----------------|
| Login | Entrar | Email, contraseña, botón Facebook |
| Catálogo | Ver títulos | UITableView o UICollectionView |
| Detalle libro | Ver precios y disponibilidad | Alquiler, garantía, total, CTA Pagar |
| Pago Yape | Cobrar | Teléfono + código verificación + total |
| Mis alquileres | Seguimiento | Estado, dueDate, UID |
| Admin libros | Inventario | Form título + lista ejemplares |
| Watson | Ayuda | Chat FAQ |
| PageView onboarding | U4 Móviles | 2–3 páginas intro |
