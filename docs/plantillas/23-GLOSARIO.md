| Título (Book) | Ficha del catálogo (obra: nombre, autor, ISBN, precios) |
| Ejemplar (Exemplar) | Libro físico concreto con **UID** único |
| UID | Identificador único del ejemplar |

| Precio de alquiler | Tarifa del período; no reembolsable |
| Yape | Medio de pago móvil (MVP simulado en app) |
| Código de verificación | Segundo dato en pantalla Yape junto al celular |
| Recojo | Retiro del ejemplar en la biblioteca |
| Core Data | Persistencia local iOS (cache) |
| REST | API HTTP JSON del backend |
| Watson | Asistente IBM de ayuda en la app |
| Product Backlog | Lista priorizada de historias Scrum |
